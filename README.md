I have not selected the final app idea yet. For now, I am using this repository to document the exploration process and develop the concept carefully before beginning implementation.

- Explore a real problem connected to scuba diving
- Build something useful rather than inventing a need for technology
- Demonstrate programming, engineering design, and problem-solving skills
- Document the project from early research through testing and reflection
- Create a project that supports my computer engineering transfer portfolio
